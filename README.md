# A/B-тест формы оплаты ЖКХ

Анализ A/B-теста упрощённой формы оплаты ЖКХ за период с 1 по 30 апреля 2024 года. Цель — проверить, повышает ли новая форма конверсию из открытия формы в успешную оплату.

Принято допущение: группа A использует старую форму, группа B — новую.

## Состав проекта

Все файлы размещаются в корне репозитория:

| Файл | Описание |
| --- | --- |
| `Volkov_VA_ZKH_analysis.ipynb` | Выполненный ноутбук с проверками данных, расчётами, графиками и выводами |
| `data.xlsx` | Исходные данные: листы «Пользователи» и «Платежи» |
| `requirements.txt` | Зависимости Python |
| `Volkov_VA_ZKH_report.pdf` | Итоговый отчёт на двух страницах |
| `README.md` | Описание проекта и инструкция запуска |

## Запуск

Требуется **Python 3.12**. Откройте терминал в папке проекта и выполните команды для macOS или Linux:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m notebook
```

В открывшемся Jupyter выберите `Volkov_VA_ZKH_analysis.ipynb` и выполните все ячейки по порядку сверху вниз.

Ноутбук читает `data.xlsx` из той же папки. Если файл находится в другом месте, измените переменную `INPUT_FILE` в первой ячейке с кодом. Исходный Excel не изменяется.

Результаты и графики уже сохранены в ноутбуке, поэтому его можно просматривать без запуска.

## Что сделано

- Проверены и обработаны пропуски, некорректные значения и конфликт групп.
- Проведён разведочный анализ данных и построена воронка оплаты.
- Рассчитаны конверсии и разница между группами.
- Выполнена статистическая проверка с учётом повторных попыток одного пользователя.
- Изучены результаты по устройствам и городам, проверена устойчивость вывода к обработке спорных записей.

Основная метрика — отношение числа успешных попыток оплаты к числу открытых форм. Для проверки использован Wald-тест с кластерной стандартной ошибкой по пользователям. Доверительный интервал получен кластерным bootstrap на 50 000 повторов с фиксированным случайным зерном. Дополнительно рассчитана доля пользователей, успешно оплативших хотя бы один раз.

## Основной результат

После очистки в основной выборке осталось **1 500 пользователей и 2 658 попыток оплаты**.

Конверсия составила **49,81% в A** и **64,40% в B**. Прирост — **14,59 процентного пункта**, 95%-й доверительный интервал — **[10,91; 18,29] п.п.**

Рекомендация — поэтапно внедрять новую форму после проверки соответствия групп версиям и причины конфликта в данных. Ограничения анализа и проверки устойчивости приведены в ноутбуке и отчёте.
